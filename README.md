# Student Task Manager

A polished Expo mobile app for organizing study tasks, tracking progress, and staying focused.

## Features
- Weekly progress dashboard
- Add a new task from the home screen
- Tap tasks to mark them complete
- Course labels, due dates, and visual priority accents
- Responsive layout for Expo Go, Android, iOS, and web

## Run locally
```bash
npm install
npx expo start
```

Press `w` for web, or scan the Expo QR code with Expo Go.

## GitHub Actions
The workflow at `.github/workflows/expo.yml` installs dependencies and runs an Expo web export on every push and pull request.
